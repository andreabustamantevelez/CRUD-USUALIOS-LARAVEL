1. QUÉ ES EL SISTEMA
----------------------------------------------------------------------
Cuentas Claras es una aplicación web de finanzas personales y familiares, en español y en
pesos colombianos (COP, siempre enteros, nunca decimales). Permite:
  - Registrar gastos diarios y administrar categorías (propias y del sistema).
  - Asignar un ícono propio a cada categoría (elegido de un catálogo de 16 opciones).
    Si el usuario o el admin no eligen uno, se usa un fallback automático (por nombre para
    las del sistema, por bloque 50/30/20 para las demás).           [NUEVO 2026-10-20]
  - Registrar gastos fijos mensuales (arriendo, servicios...) con vencimientos y alertas
    automáticas 3 días antes.
  - Simular créditos (sistema francés) y guardar las simulaciones.
  - Ver un informe mensual contra la regla 50/30/20.
  - Metas de ahorro INDIVIDUALES o COMPARTIDAS entre DOS usuarios "familiar" (máx. 2),
    con privacidad de aportes.
  - Cambiar el tipo de cuenta (estándar <-> familiar) desde Ajustes. Exclusivo para
    estandar y familiar; el admin no tiene acceso.
  - Cambiar el correo electrónico con verificación por enlace (token de un solo uso,
    1 hora, correo al NUEVO destino).
  - Administración (usuarios, roles, categorías del sistema, estadísticas agregadas).
    El admin también puede elegir el ícono de cada categoría del sistema.
                                                                     [NUEVO 2026-10-20]
  - Modo claro / oscuro con persistencia en localStorage y favicon dinámico.
  - Tinte por rol: verde (estándar), morado (familiar), azul (administrador).
  - Iconografía por categoría (SVG propio, color por bloque 50/30/20, personalizable).
                                                                     [NUEVO 2026-10-20]
  - Skip link, página 403 y 404 personalizadas, expiración de sesión (15 min),
    correos con identidad de marca.
El diseño visual YA ESTÁ HECHO (vistas Blade + CSS + JS). EL DISEÑO NO SE CAMBIA.

4. ROLES (3) Y QUÉ PUEDE HACER CADA UNO
----------------------------------------------------------------------
  estandar ........ gastos, categorías (con ícono elegible), gastos fijos,
                    notificaciones, simulador, informes, panel, ajustes
                    (perfil con ingreso mensual, tipo-cuenta, eliminar cuenta,
                    cambio de correo) y METAS INDIVIDUALES. NO entra a
                    administración.
  familiar ........ todo lo del estándar + metas COMPARTIDAS y puede ACEPTAR
                    invitaciones a metas compartidas.
  administrador ... SOLO administración. En Ajustes, únicamente `perfil`
                    (nombre, correo, contraseña) y `confirmar-correo`.
                    NO tiene ingreso mensual: el campo no se muestra y la regla
                    prohibitedIf lo rechaza si llega por POST.       [NUEVO 2026-10-20]
                    NO puede cambiar tipo de cuenta ni eliminar su cuenta desde
                    Ajustes (solo desde /admin/usuarios si hay otro admin).
                    NUNCA ve montos ni datos financieros de nadie.
                    Recibe 403 en gastos, créditos, metas, informes y panel.
                    Puede elegir el ícono de cada categoría del sistema desde
                    /admin/categorias.                                [NUEVO 2026-10-20]
Estado de cuenta: users.activo (booleano).
"rol" y "activo" NO son asignables en masa.
Ocultar un enlace del menú NO protege: middleware + Policies.
Cambio de tipo de cuenta: Ajustes > Tipo de cuenta, vía ServicioCuentas::cambiarTipo.
No cierra la sesión. Regla: estandar -> familiar siempre; familiar -> estandar se
bloquea con metas compartidas activas. Cambio de rol por admin:
ServicioCuentas::cambiarRol.
Cambio de correo: Ajustes > Perfil, requiere contraseña actual y verificación por
enlace al NUEVO correo. Cierra la sesión al confirmar.

Efecto visual del rol:
  Estándar → botones/avatar/ítems activos/logo/favicon en primary (verde).
  Familiar → esos mismos elementos en tertiary (morado).
  Administrador → esos mismos elementos en la familia --admin-* (azul Core Blue).
  El cambio se aplica en el siguiente render. El favicon se regenera vía JS.
  Los correos también respetan el tinte del rol (vía PHP).
  Los iconos de categoría usan colores por BLOQUE 50/30/20, no por rol:
  necesidades (--need, azul), discrecionales (--want, morado), ahorro (--save, verde).

11. REGLAS DE NEGOCIO QUE NO SE PUEDEN ROMPER
----------------------------------------------------------------------
Seguridad y privacidad
  - Toda consulta parte del usuario autenticado. Se prueba con dos usuarios.
  - Policy antes de leer, editar o borrar. Contraseñas con hash. CSRF.
  - El administrador nunca toca datos financieros. Ajeno -> 403.
  - Mensajes de error genéricos hacia afuera.
  - Límite de intentos en login y recuperación.
  - Consentimiento de datos obligatorio en el registro, con fecha.
  - Expiración de sesión por inactividad: 15 minutos vía middleware
    'sesion.inactividad'. Requiere SESSION_LIFETIME (480) > LIMITE_MINUTOS (15).
    Mensaje "Tu sesión expiró por inactividad" en el login.
Metas
  - Individual: solo creador. Estándar y familiar.
  - Compartida: solo familiar, máx. 2 participantes.
  - Invitar a un estándar: permitido + notificación especial.
  - Aceptar: requiere ser familiar.
  - PRIVACIDAD: detalle muestra total conjunto y aporte PROPIO.
  - Familiar -> estándar bloqueado con metas compartidas activas.
Cambio de tipo de cuenta
  - Ajustes > Tipo de cuenta, vía ServicioCuentas::cambiarTipo.
  - Solo estandar y familiar. Admin recibe 403.
  - NO cierra la sesión. 'rol' no es fillable.
Cambio de rol (por admin)
  - Vía ServicioCuentas::cambiarRol. No cierra la sesión del usuario cambiado.
  - Bloquear si quita admin al último admin activo.
  - Bloquear si baja de familiar a estandar con metas compartidas activas.
Cambio de correo
  - Ajustes > Perfil. Requiere contraseña actual si cambia correo o contraseña.
  - Token SHA-256, 1 hora, correo al NUEVO destino.
  - Correo actual sigue activo hasta confirmar. Al confirmar se cierra la sesión.
  - Correo actual y pendiente deben ser únicos.
Eliminar cuenta / suspender
  - Vía ServicioCuentas. No dejar el sistema sin admin activo.
  - Admin no puede eliminarse a sí mismo desde el panel.
  - Admin tampoco puede eliminar su cuenta desde Ajustes.
  - Vaciar remember_token antes de Auth::logout.
Restablecer contraseña
  - Enlace de un solo uso, vence en 30 minutos (AUTH_PASSWORD_RESET_EXPIRE).
  - Mensaje neutro. Correo con identidad de marca.
Gastos fijos y alertas
  - Solo mensuales. Si el mes no tiene ese día, último día del mes.
  - Alerta a 3 días y una de vencido. Comando diario IDEMPOTENTE.
  - Vencido cancela por_vencer pendiente y crea vencido.
  - Marcar pagado cancela la alerta pendiente.
  - Cada gasto fijo muestra su icono por categoría (--need/--want/--save).
Simulador de créditos
  - Tasa mensual vencida, sistema francés, redondeo final.
  - Semáforo: <20% saludable, 20-30% moderado, >30% riesgo.
  - Solo simulaciones, no créditos reales.
Informes 50/30/20
  - Agrupa por bloque y categoría. Informe guardado no se recalcula.
Dashboard
  - "Disponible del mes" = ingreso − gastos; no se guarda saldo.
Administración
  - Admin nunca ve datos financieros individuales.
  - Categorías del sistema se desactivan, no se borran.
  - Sistema nunca queda sin admin activo.
  - Admin no puede eliminarse a sí mismo desde el panel.
  - Admin TAMPOCO tiene ingreso mensual. El campo no aparece en
    Ajustes > Perfil y UpdatePerfilRequest lo rechaza si llega.      [NUEVO 2026-10-20]
  - Admin puede elegir el ícono de las categorías del sistema en
    /admin/categorias.                                               [NUEVO 2026-10-20]
  - Estadísticas solo con COUNT y agregados.
Categorías
