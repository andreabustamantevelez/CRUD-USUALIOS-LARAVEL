1. QUÉ ES EL SISTEMA
----------------------------------------------------------------------
Cuentas Claras es una aplicación web de finanzas personales y familiares, en español y en
pesos colombianos (COP, siempre enteros, nunca decimales). Permite:
  - Registrar gastos diarios y administrar categorías (propias y del sistema).
  - Asignar un ícono propio a cada categoría (elegido de un catálogo de 16 opciones).
    Si el usuario o el admin no eligen uno, se usa un fallback automático (por nombre para
    las del sistema, por bloque 50/30/20 para las demás).
  - Registrar gastos fijos mensuales (arriendo, servicios...) con vencimientos y alertas
    automáticas 3 días antes.
  - Simular créditos (sistema francés) y guardar las simulaciones.
  - Ver un informe mensual contra la regla 50/30/20.
  - Metas de ahorro INDIVIDUALES o COMPARTIDAS entre DOS usuarios "familiar" (máx. 2),
    con privacidad de aportes.
  - Cambiar el tipo de cuenta (estándar <-> familiar) desde Ajustes. Exclusivo para
    estandar y familiar; el admin no tiene acceso.
  - Cambiar el correo electrónico con verificación por enlace (token de un solo uso,
    1 hora, correo al NUEVO destino).
  - Administración (usuarios, roles, categorías del sistema, estadísticas agregadas
    y dashboard del administrador en /admin/panel).
  - El admin también puede elegir el ícono de cada categoría del sistema.
  - Auditoría de acciones del admin en /admin/auditoria (solo lectura).  [NUEVO 2026-10-22]
  - Modo claro / oscuro con persistencia en localStorage y favicon dinámico.
  - Tinte por rol: verde (estándar), morado (familiar), azul (administrador).
  - Iconografía por categoría (SVG propio, color por bloque 50/30/20, personalizable).
  - Skip link, página 403 y 404 personalizadas, expiración de sesión (15 min),
    correos con identidad de marca.
  - Seguridad reforzada en J9:                                              [NUEVO 2026-10-22]
    · CSP (Content-Security-Policy) + X-Frame-Options + nosniff + HSTS.
    · Notificaciones de seguridad por correo (password/email/account/login).
    · Re-autenticación (current_password) para acciones destructivas.
    · Registro de auditoría de cada cambio hecho por el admin.
    · Notificación al usuario cuando sus intentos de login se bloquean.
El diseño visual YA ESTÁ HECHO (vistas Blade + CSS + JS). EL DISEÑO NO SE CAMBIA.

Equipo: Juan (base, seguridad, reglas), Nikol (dinero del día a día), Valeria (cálculo y
análisis). Tareas J1..J9, N1..N5, V1..V5.
