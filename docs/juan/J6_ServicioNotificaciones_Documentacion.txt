3. CONTRATO C4 - EL SERVICIO
----------------------------------------------------------------------
Firma y comportamiento:

  crear(User $usuario, string $tipo, string $mensaje, array $opciones = []): Notificacion
      $opciones admite: pago_gasto_fijo_id, meta_id, clave_unica.
      Si clave_unica ya existe para ese usuario:
        - estado = 'cancelada' -> se reactiva a 'pendiente' con el mensaje nuevo;
        - estado = 'pendiente' | 'leida' -> se deja como está.
      Sin clave_unica: siempre crea una fila nueva.

  contarPendientes(User $usuario): int

  cancelarPorPago(User $usuario, PagoGastoFijo $pago): int
      Cancela todas las pendientes ligadas a ese pago.

  cancelarPorGastoFijo(User $usuario, GastoFijo $gastoFijo): int
      Cancela todas las pendientes ligadas a cualquier pago del gasto fijo.

  marcarLeida(Notificacion $notificacion): void
      Solo cambia si estaba pendiente.

  marcarTodasLeidas(User $usuario): int

Constantes para no escribir strings a mano:
  TIPO_POR_VENCER, TIPO_VENCIDO, TIPO_INVITACION_META,
  TIPO_INVITACION_META_REQUIERE_FAMILIAR, TIPO_RESPUESTA_META,
  TIPO_META_FINALIZADA, TIPO_META_ABANDONADA
  ESTADO_PENDIENTE, ESTADO_LEIDA, ESTADO_CANCELADA

4. CÓMO FUNCIONA EL COMANDO DIARIO
----------------------------------------------------------------------
  php artisan alertas:gastos-fijos [--fecha=YYYY-MM-DD]

  1. Fecha por defecto: hoy. Con --fecha se puede simular otro día (útil en pruebas).
  2. Recorre usuarios con activo = true y rol en (estandar, familiar), en lotes de 100.
  3. Por cada usuario llama a ServicioGastosFijos::proximosAVencer($u, $fecha, 3)
     y a vencidos($u, $fecha). Esos métodos ya generan los pagos del mes y marcan vencidos.
  4. Por cada pago próximo a vencer:
       - clave_unica = "por_vencer:{pago_id}";
       - si ya hay una pendiente con esa clave, no cuenta como nueva;
       - crea con tipo 'por_vencer'.
  5. Por cada pago vencido:
       - cancela la alerta 'por_vencer' pendiente si existía;
       - clave_unica = "vencido:{pago_id}";
       - crea con tipo 'vencido'.
  6. Idempotencia real: la combinación (user_id, clave_unica) es única en la tabla; el
     servicio no crea una segunda fila, y si estaba cancelada, la reactiva.
  7. La salida imprime cuántas nuevas por vencer y cuántas nuevas vencidas.

Registro en routes/console.php:
  Schedule::command('alertas:gastos-fijos')->dailyAt('07:00');
  El cron del servidor debe correr `php artisan schedule:run` cada minuto (J9).

5. LO QUE CAMBIÓ EN EL CÓDIGO DE NIKOL (AVISO)
----------------------------------------------------------------------
  ServicioGastosFijos::marcarPagado
      Antes: Notificacion::...->update(['estado' => 'cancelada'])
      Ahora: app(ServicioNotificaciones::class)->cancelarPorPago($usuario, $pago)

  GastoFijoController::cancelarNotificacionesPendientes
      Antes: Notificacion::...->update(['estado' => 'cancelada'])
      Ahora: app(ServicioNotificaciones::class)->cancelarPorGastoFijo(auth()->user(), $gastoFijo)

  ServicioGastosFijos::proximosAVencer
      Antes: whereBetween('fecha_vencimiento', [$hoy, $limite])
             (el día límite quedaba fuera porque la columna se guarda como datetime)
      Ahora: whereDate('fecha_vencimiento', '>=', $hoy)
             ->whereDate('fecha_vencimiento', '<=', $limite)

  Se quitó `use App\Models\Notificacion;` de ServicioGastosFijos y GastoFijoController.

8. CÓMO PROBARLO A MANO
----------------------------------------------------------------------
  1. php artisan migrate:fresh --seed   y   php artisan serve
  2. Entra como estandar@test.com. Crea un gasto fijo con día de vencimiento = hoy + 3.
  3. Corre: php artisan alertas:gastos-fijos
     -> "Nuevas por vencer: 1. Nuevas vencidas: 0."
  4. Recarga la app. La campana sube a 1.
  5. Corre el comando otra vez: "Nuevas por vencer: 0. Nuevas vencidas: 0."
     -> la campana sigue en 1 (idempotencia).
  6. Marca el gasto fijo como pagado. La campana baja a 0.
  7. Crea un gasto fijo con día de vencimiento anterior a hoy. Corre el comando:
     "Nuevas vencidas: 1". En la campana sube a 1.
  8. Simular otra fecha: php artisan alertas:gastos-fijos --fecha=2026-11-25
  9. Pruebas automáticas: php artisan test --filter=AlertasTest
