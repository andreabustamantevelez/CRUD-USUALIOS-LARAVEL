3. DECISIÓN #23 CERRADA
----------------------------------------------------------------------
La tabla categorias ganó la columna activa (boolean, default true) con índice
compuesto (user_id, activa).

Regla:
  - Las categorías del sistema (user_id = null) se DESACTIVAN, no se borran.
  - Al desactivar una: deja de aparecer al registrar gastos nuevos.
  - Los gastos históricos que la usan siguen mostrándola (la FK no se rompe).
  - El admin solo gestiona las del sistema. Las personales no aparecen aquí.

Aviso a Nikol (N1, N2): sus pantallas pueden filtrar con Categoria::activas()
para no mostrar las desactivadas. No es bloqueante mientras no se desactive
ninguna, pero debe sumarlo cuando toque N1 o N2.

4. SERVICIO DE CUENTAS - MÉTODOS NUEVOS
----------------------------------------------------------------------
  cambiarRol(User, string $nuevoRol): void
      - Admite estandar|familiar|administrador.
      - Si se quita admin a alguien, verifica que no sea el último admin activo.
      - Si baja de familiar a estandar, no debe tener metas compartidas activas.
      - Mismo rol: no hace nada.

  suspender(User): void
      - activo = false.
      - Si es el último admin activo, bloquea.

  reactivar(User): void
      - activo = true.

  Reutiliza verificarUltimoAdministrador() (existente desde J8a).

Mensajes de ValidationException:
  - "No puedes eliminar tu cuenta porque eres el único administrador activo
     del sistema." (mismo mensaje que ya usaba eliminarCuenta)
  - "Debes finalizar o cancelar las metas compartidas activas antes de bajar
     a estándar."

5. CONTROLADORES
----------------------------------------------------------------------
Admin\UsuarioController
  index(Request): View
      - Filtros: rol, estado (activos|suspendidos), buscar (nombre o correo).
      - Paginado 20 con withQueryString.
      - SOLO campos: nombre, email, rol, activo. Nunca montos.
  cambiarRol(ActualizarRolRequest, User): RedirectResponse
      - Delega en ServicioCuentas::cambiarRol. Toast: "Rol actualizado".
  cambiarEstado(ActualizarEstadoRequest, User): RedirectResponse
      - Suspende o reactiva. Toast: "Cuenta suspendida" / "Cuenta activada".
  destroy(Request, User): RedirectResponse
      - No permite eliminarse a sí mismo desde el panel.
      - Delega en ServicioCuentas::eliminarCuenta. Toast: "Usuario eliminado".

Admin\CategoriaSistemaController
  index(Request): View
      - Categorías con user_id null, con withCount(['gastos','gastosFijos']).
      - Pasa $resumen (total, activas, inactivas) y $bloques (metadatos 50/30/20).
  store(StoreCategoriaSistemaRequest): RedirectResponse
      - Crea con user_id null, activa true. Toast: "Categoría creada".
  update(UpdateCategoriaSistemaRequest, Categoria): RedirectResponse
      - abort_unless(user_id === null, 403). Toast: "Categoría actualizada".
  desactivar(Request, Categoria): RedirectResponse
      - abort_unless(user_id === null, 403).
      - Toggle activa. Toast: "Categoría activada" / "Categoría desactivada".

Admin\EstadisticaController
  index(): View
      - Conteos: total usuarios, por rol, por estado, total notificaciones,
        notificaciones por tipo (GROUP BY).
      - NUNCA consulta montos ni datos financieros.
